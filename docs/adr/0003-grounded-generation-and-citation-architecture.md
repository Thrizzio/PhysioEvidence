# ADR 0003: Grounded Evidence Generation and Source Attribution

## Context
In clinical physiotherapy, generative AI hallucinations or unverified extrapolations pose genuine clinical risks. Practitioners need answers grounded exclusively in peer-reviewed scientific literature with direct, verifiable source citations. If literature is sparse or lacks empirical evidence for a clinical inquiry, the system must transparently report insufficient evidence rather than confabulating clinical recommendations.

## Decision
We implement a strictly grounded generation layer (`generation/`) and unified orchestrator (`rag/`) adhering to:
1. **Source Attribution & Citation Syntax**: Every claim generated by the LLM must be explicitly attributed using bracketed references `[Source N]` mapped directly to retrieved evidence metadata (title, section, page numbers).
2. **Refusal on Insufficient Evidence**: The system prompt strictly directs the LLM that if the retrieved context is insufficient or silent on the question, it must explicitly respond with a standardized insufficiency disclosure ("Based on the retrieved research literature, there is insufficient evidence to...").
3. **Context Assembly Budgeting**: Raw chunk contents are formatted with structural headers (`[Source N: <Title>, Section: <Section>, Pages: <P1-P2>]`) within a configurable token/character ceiling.
4. **Decoupled LLM Provider Interface**: `LLMProvider` is an abstract interface, with `GeminiLLMProvider` for production and `MockLLMProvider` for offline deterministic testing.

## Consequences
- **Positive**: High trust, verifiable clinical outputs with direct links to academic papers and page numbers.
- **Positive**: Prevents medical misinformation and out-of-context extrapolations.
- **Considerations**: The LLM will strictly decline to answer questions outside the indexed corpus, which is the desired behavior for an evidence retrieval platform.
